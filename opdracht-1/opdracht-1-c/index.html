Intro

Welkom op mijn website! Deze website is gemaakt met HTML en CSS. Ik gebruik een Grid System om de website in verschillende kolommen te verdelen.

Uitleg

Een Grid System bestaat uit 12 kolommen. Met col-4 gebruiken we vier kolommen. Met col-8 gebruiken we acht kolommen. Zo kunnen we een website makkelijk indelen.

Conclusie

Ik heb geleerd hoe ik een website kan maken met containers, rows en columns. Ook heb ik geleerd om Flexbox te gebruiken.
